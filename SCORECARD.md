[the v3.0 plan](https://github.com/SeanningTatum/cf-saas-starter-react-router/issues/58), each
scored 1 to 5. The plan's rule: a score is a check that runs. So each row names the checks that run
today and what is still missing. A score with no check behind it is a guess and is marked so.

## Reading it

- The six areas about the template's own code sit at 3 to 5.
- The four lowest areas all wait on a real harness in `claude/` (B-08). All four score below their
  start because the old repo had a working harness and this one has a stand-in.
- Deployment has run end to end on a test project: full and gradual releases, a failed smoke test
  rolled back, a missing pinning rule backed out, the rule made, a rollout raised and backed out, a
  D1 restore, and the rollout's events seen in PostHog.
