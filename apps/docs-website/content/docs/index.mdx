---
title: Getting started
description: Create a project and run it.
---

Software Factory builds a SaaS for Cloudflare Workers from blocks: a database, sign-in, billing,
file uploads and background jobs. It wires the ones you pick together, tests them and can deploy
the result. Each project also gets workflows for Claude Code.

## Create a project

```bash
bunx create-software-factory my-app --features db,auth
```

## Run it

```bash
cd my-app
bun run dev
```
